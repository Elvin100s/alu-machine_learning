# Hidden Markov Models

This directory contains work with Markov chains and Hidden Markov Models.

| File | Description |
| --- | --- |
| `0-markov_chain.py` | Probability of a Markov chain being in each state after `t` iterations |
| `1-regular.py` | Steady state probabilities of a regular Markov chain |
| `2-absorbing.py` | Determines whether a Markov chain is absorbing |
| `3-forward.py` | Forward algorithm for a hidden Markov model |
| `4-viterbi.py` | Viterbi algorithm: most likely sequence of hidden states |
| `5-backward.py` | Backward algorithm for a hidden Markov model |
| `6-baum_welch.py` | Baum-Welch algorithm: estimates the transition and emission probabilities |
