# Temporal Difference

This directory contains model-free prediction and control algorithms for
reinforcement learning, run on OpenAI Gym's `FrozenLake8x8-v0`.

| File | Description |
| --- | --- |
| `0-monte_carlo.py` | Monte Carlo value estimation from complete episode returns |
| `1-td_lambtha.py` | TD(λ) value estimation with eligibility traces |
| `2-sarsa_lambtha.py` | SARSA(λ) on-policy control with epsilon-greedy exploration |
